# Currency Converter App 💱🌍

A user-friendly **Currency Converter** built using **HTML**, **CSS**, and **JavaScript**, with real-time exchange rates powered by a free API.

## 🌟 Features

- 🌐 Two dropdowns for selecting **source** (From) and **target** (To) currencies.
- 🚩 **Country flags** update automatically when currency is changed.
- 💵 User can input any amount and click **Convert** to see real-time exchange.
- 🔗 Integrated with a **free currency converter API** for up-to-date rates.

## 🧠 How It Works

1. Select a currency in the **From** and **To** dropdowns.
2. Flags update based on selected countries.
3. Enter the amount to be converted.
4. Click the **Convert** button to get the converted value.

## 🔧 Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Free Currency Converter API
