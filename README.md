# Currency Converter Web App
This web app helps to convert currency of one nation to any other nation as per the user's choice. The project is fully developed from scratch using HTML, CSS and JavaScript. A simple currency converter API is integrated
to make the currency conversion possible. fetch API, async-await, events are the general concepts of JS used in this project. Another API to display flag for all the nations is also integrated to make the user experience a better and easy to identify nationality rather than using only country codes.
